안녕하세요! 이번에는 CSS 선택자(selector) 3종 세트(`01_CSS선택자1`, `02_CSS선택자2`, `03_css선택자3`)를 정리해봤습니다.
선택자마다 기호가 많이 나와서, 기호 위주로 확실히 정리하는 데 집중했습니다.

## 1. 스타일을 적용하는 두 가지 방법

| 방법 | 위치 | 특징 |
|---|---|---|
| 내부 스타일시트 | `<head>` 안 `<style>` 태그 | 한 파일 안에서 바로 확인 가능하지만, 파일이 길어지면 head가 지저분해짐 |
| 외부 스타일시트 | 별도 `.css` 파일 | `<link rel="stylesheet" href="파일명.css">`로 연결. 여러 HTML에서 재사용 가능 |

```html
<link rel="stylesheet" href="selector.css">
```

## 2. 기본 선택자

| 선택자 | 기호 | 의미 |
|---|---|---|
| 전체 선택자 | `*` | 문서 안의 모든 요소 선택 |
| 태그 선택자 | 태그명 | 해당 태그를 쓰는 요소 전부 선택 |
| id 선택자 | `#` | `id="값"`인 요소 하나만 선택(문서 내 유일) |
| class 선택자 | `.` | `class="값"`인 요소 전부 선택(여러 개 가능) |

```css
* { color: red; }
li { color: blue; }
#id3 { color: green; }
.class3 { color: aquamarine; }
```

## 3. 속성 선택자

기본 선택자 뒤에 `[속성명=속성값]` 형태로 붙여서, 특정 속성·값을 가진 요소만 골라낼 수 있습니다.

| 기호 | 의미 | 예시 |
|---|---|---|
| `[속성]` | 해당 속성이 있기만 하면 선택 | `[disabled]` |
| `[속성=값]` | 속성 값이 정확히 일치 | `div[name=name2]` |
| `[속성~=값]` | 속성 값이 공백으로 구분된 단어 중 하나로 포함 | `div[name~=name1]` |
| `[속성^=값]` | 속성 값이 해당 문자로 시작(접두사) | `div[name^=name]` |
| `[속성$=값]` | 속성 값이 해당 문자로 끝남(접미사) | `div[class$=class]` |
| `[속성*=값]` | 속성 값 어디든 해당 문자를 포함 | `div[class*=div]` |
| `[속성\|=값]` | 속성 값이 정확히 일치하거나, 뒤에 `-`가 붙어서 시작 | `div[class\|=class]` → `class`, `class-...` 모두 선택 |

```css
div[name=name2] { background: orange; }
div[name~=name1] { background: yellow; }
div[name^=name] { background: blueviolet; }
div[class$=class] { background: white; }
div[class*=div] { background: plum; }
```

## 4. 결합자(관계 선택자)

선택자 사이에 어떤 기호를 넣느냐에 따라 "어떤 관계의 요소를 고를지"가 달라집니다.

| 기호 | 이름 | 의미 |
|---|---|---|
| (공백) | 후손 선택자 | 하위 요소 전부(자손의 자손까지 포함) |
| `>` | 자손 선택자 | 바로 한 단계 아래 요소만 |
| `+` | 인접 형제 선택자 | 바로 다음에 오는 형제 요소 하나 |
| `~` | 일반 형제 선택자 | 뒤에 오는 형제 요소 전부 |

```css
#test1 ul { background: chocolate; }     /* 후손: ul이 몇 단계 아래 있어도 선택 */
#test1 > h4 { background: hotpink; }     /* 자손: 바로 아래 h4만 */
#div-test1 + div { background: green; }  /* 형제: div-test1 바로 다음 형제 */
```

> 자손(child)과 후손(descendant)을 혼동하기 쉬운데, `>`는 "한 단계 아래만", 공백은 "몇 단계든 아래 전부"라고 기억하면 헷갈리지 않습니다.

## 5. 반응 선택자 · 상태 선택자

사용자의 행동이나 입력 양식의 상태에 따라 달라지는 선택자입니다. 콜론(`:`) 하나로 씁니다.

| 선택자 | 의미 |
|---|---|
| `:hover` | 마우스가 올라와 있을 때 |
| `:active` | 클릭하는 순간 |
| `:focus` | 입력 칸을 클릭해서 포커스가 갔을 때 |
| `:enabled` | 사용 가능한(활성화된) 입력 요소 |
| `:disabled` | `disabled` 속성이 붙어 사용 불가능한 요소 |
| `:checked` | 체크박스/라디오가 선택된 상태 |

```css
#hover-test:hover { background: darkgreen; }
#userId:focus, #userPwd:focus { background: hotpink; }
input[type=checkbox]:checked { width: 100px; height: 100px; }
option:disabled { background: red; }
```

## 6. 구조 선택자

형제 관계 안에서 "몇 번째인지" 위치로 골라내는 선택자입니다.

| 선택자 | 의미 |
|---|---|
| `:first-child` | 형제 중 첫 번째 요소 |
| `:last-child` | 형제 중 마지막 요소 |
| `:nth-child(n)` | 형제 중 n번째 요소 |
| `:nth-child(2n-1)` | 홀수 번째 요소(`2n`은 짝수, `2n-1`은 홀수) |
| `:nth-last-child(n)` | 뒤에서 n번째 요소 |

```css
#test :first-child { background: rebeccapurple; }
#test :nth-child(2) { background: darkblue; }
#test :nth-child(2n-1) { background: darkcyan; }
#test :nth-last-child(4) { background: darkgreen; }
```

## 7. 부정 선택자

지금까지의 선택 조건을 정반대로 뒤집는 선택자입니다.

| 선택자 | 의미 |
|---|---|
| `:not(조건)` | 조건에 해당하지 않는 요소만 선택 |

```css
/* 짝수 번째(even)가 아닌, 즉 홀수 번째 p만 선택 */
#test2 p:not(:nth-child(even)) { background: orange; }
```

## 8. 문자(가상 요소) 선택자

요소 전체가 아니라 텍스트의 일부만 골라 스타일을 줄 수 있습니다. 콜론 두 개(`::`)를 씁니다.

| 선택자 | 의미 |
|---|---|
| `::first-letter` | 텍스트의 첫 글자 |
| `::first-line` | 텍스트의 첫 줄 |
| `::selection` | 사용자가 마우스로 드래그해서 선택한 부분 |

```css
#test3 p::selection {
    color: red;
}
```

## 9. 기호로 한눈에 보기 (헷갈렸던 것 위주 정리)

| 기호 | 위치 | 의미 |
|---|---|---|
| `*` | 단독 | 전체 선택자 |
| `#` | 선택자 앞 | id 선택자 |
| `.` | 선택자 앞 | class 선택자 |
| `[ ]` | 선택자 뒤 | 속성 선택자 시작 |
| `=` | `[ ]` 안 | 속성 값이 정확히 일치 |
| `~=` | `[ ]` 안 | 공백으로 구분된 단어 중 하나로 포함 |
| `^=` | `[ ]` 안 | 값이 이 문자로 시작(접두사) |
| `$=` | `[ ]` 안 | 값이 이 문자로 끝남(접미사) |
| `*=` | `[ ]` 안 | 값 어디든 이 문자를 포함 |
| `\|=` | `[ ]` 안 | 값이 정확히 일치 또는 `-`로 시작하는 값 |
| (공백) | 선택자 사이 | 후손 선택자(몇 단계든 아래 전부) |
| `>` | 선택자 사이 | 자손 선택자(바로 한 단계 아래만) |
| `+` | 선택자 사이 | 인접 형제(바로 다음 형제 하나) |
| `~` | 선택자 사이 | 일반 형제(뒤에 오는 형제 전부) |
| `:` | 선택자 뒤 | 반응/상태/구조/부정 선택자(가상 클래스) |
| `::` | 선택자 뒤 | 문자(가상 요소) 선택자 |

## 마무리

이번에 배운 걸 한 문장으로 정리하면 이렇습니다.

> `*`/`#`/`.`으로 기본 대상을 고르고, `[ ]`로 속성을 걸러내고, 공백/`>`/`+`/`~`로 관계를 좁히고, `:`/`::`로 상태나 위치, 텍스트 일부까지 골라낼 수 있다.

기호가 많아서 헷갈리기 쉬운데, 표를 옆에 두고 실습 파일을 다시 열어보면서 하나씩 확인하니 감이 잡혔습니다.
